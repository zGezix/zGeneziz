# หมากฮอสสกิลเทพ

หมากฮอสไทย 3D พร้อมการ์ดสกิลสไตล์อนิเมะ เล่นในเบราว์เซอร์ได้ทุกเครื่อง

- เล่นกับบอท, 2 คนเครื่องเดียว, หรือออนไลน์กับเพื่อนด้วยรหัสห้อง 5 ตัว
- กินหมากแล้วมีโอกาส 60% เปิดการ์ดพลัง 3 ใบ (ธรรมดา / หายาก / ตำนาน)
- การ์ดตำนาน 3 ใบมีคัตซีนท่าไม้ตาย
- ตั้งชื่อและแต่งหมากได้ (สี, ลาย, ผิวสัมผัส)
- โหมด "ลื่นไหล" สำหรับเครื่องที่แลค

## เปิดเล่นบน GitHub Pages

1. ไปที่ Settings → Pages ของ repo นี้
2. Source เลือก "Deploy from a branch", Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## เทคนิค

ไฟล์เดียว `index.html` ใช้ three.js r128 สำหรับภาพ 3D และ MQTT ผ่าน WebSocket (เซิร์ฟเวอร์สาธารณะ) สำหรับเล่นออนไลน์ ไม่มีเซิร์ฟเวอร์ของตัวเอง
